Custom Domain guide

Create a Cloudflare API token

Create a narrowly scoped User API Token. Do not use an Account API Token or Global API Key.

  1. Open the token pageGo to Cloudflare → My Profile → API Tokens, choose Create Token, then Create Custom Token.
  2. Name the tokenUse a recognizable name such as Agent Remote or Agent Remote – example.com.
  3. Add exactly these three permissions Select the values in each dropdown row, then use + Add more for the next row.
    ScopePermissionAccess
    AccountCloudflare TunnelEdit / Write
    ZoneDNSEdit / Write
    ZoneZoneRead
    Seeing “Write” instead of “Edit”?Choose Write. Cloudflare's newer UI uses it for the same write-level permission needed here.
  4. Limit the resourcesUnder Account Resources, choose Include → Specific account and select your account. Under Zone Resources, choose Include → Specific zone and select the domain you will connect. Avoid “All accounts” and “All zones”.
  5. Leave optional restrictions emptyLeave Client IP Address Filtering blank unless this Mac has a fixed public IP. Leave TTL unset for uninterrupted reconnects; if you set an expiry, you must create and paste a replacement token later.
  6. Create and copy the tokenChoose Continue to summary, verify the three permissions and selected resources, then choose Create Token. Copy the secret immediately—Cloudflare shows it only once.
  7. Return here and validatePaste the secret into Cloudflare API token and choose Validate token. Agent Remote stores the validated token in your Mac Keychain.
